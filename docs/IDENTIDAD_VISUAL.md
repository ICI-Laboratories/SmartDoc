# Identidad visual de SARA DocReader

Fuente proporcionada por el usuario: `ICI-Laboratories/IdentidadGrafica/Propuesta-Identidad-SARA`, manual unificado v0.4.0.

Se incorporaron los tokens originales en `web/src/lib/sara-tokens.css`, los logotipos horizontales para claro/oscuro en `web/static/brand/` y el icono de aplicación en `web/static/favicon.svg`. Los SVG se copiaron sin redibujarlos. Inter y Manrope se sirven localmente mediante Fontsource; el navegador no necesita Google Fonts.

La implementación usa superficies sólidas, ciruela para acciones, contraste tonal, foco visible, estados acompañados de texto y controles de al menos 44 px. Las capturas de pruebas contienen documentos sintéticos, nunca datos del laboratorio. Se verificaron biblioteca y acceso en escritorio/móvil y tema oscuro; la conformidad completa de accesibilidad requiere una auditoría específica.
